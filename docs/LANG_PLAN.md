# 🌍 LANG_PLAN.md --- Language Strategy for Clicuha

Документ визначає, де потрібна мультимовність, де ні, і де можна
замінити текст універсальними іконками.

------------------------------------------------------------------------

# 1️⃣ Де мультимовність ОБОВʼЯЗКОВА

## 🔹 Головне меню

-   Головна
-   Клікухи
-   Профіль
-   Налаштування

## 🔹 Авторизація

-   Увійти
-   Зареєструватися
-   Вийти
-   Помилки авторизації

## 🔹 Повідомлення системи

-   Успіх
-   Помилка
-   Підтвердження дії

## 🔹 Налаштування користувача

-   Мова
-   Приватність
-   Тема
-   Зміна пароля

------------------------------------------------------------------------

# 2️⃣ Де мультимовність БАЖАНА (але не критична)

-   Підказки (tooltips)
-   FAQ
-   Модальні вікна
-   Адмінка (другорядне для юзера)

------------------------------------------------------------------------

# 3️⃣ Де мультимовність НЕ потрібна

## 🔹 Контент

-   клікухи\
-   описи\
-   коментарі\
-   приватні повідомлення\
-   тексти AI

## 🔹 Технічні та інтернаціональні слова

-   Login / Logout\
-   Edit / Delete\
-   Feed\
-   Save\
-   Upload

Тут переклад не дає користі.

------------------------------------------------------------------------

# 4️⃣ Де краще використовувати ІКОНКИ замість тексту

  Дія            Символ   Пояснення
  -------------- -------- ---------------------
  Пошук          🔍       інтернаціонально
  Створити       ➕       зрозуміло будь-кому
  Редагувати     ✏️       стандарт
  Видалити       🗑        зрозуміло
  Лайк           ❤️       універсально
  Коментар       💬       зрозуміло
  Профіль        👤       без перекладу
  Налаштування   ⚙️       завжди однаково
  Список         📄       логічно

Іконки = мінус 30--40% перекладів.

------------------------------------------------------------------------

# 5️⃣ Структура мовних файлів

    /lang/
       ua.php
       en.php
       pl.php

### Приклад `ua.php`:

``` php
return [
  'menu_home' => 'Головна',
  'menu_profile' => 'Профіль',
  'menu_nicknames' => 'Клікухи',
  'btn_save' => 'Зберегти',
  'msg_error' => 'Сталася помилка',
];
```

### Використання:

``` php
$lang = include __DIR__ . "/lang/{$currentLang}.php";
echo $lang['menu_home'];
```

------------------------------------------------------------------------

# 6️⃣ Логіка вибору мови

1.  Якщо юзер вибрав мову → cookie\
2.  Якщо cookie немає → читаємо мову браузера\
3.  Якщо мова не підтримується → fallback = English

------------------------------------------------------------------------

# 7️⃣ Принципи економії перекладів

-   Короткі кнопки --- англійською\
-   Довгі тексти --- мультимовні\
-   Все, що можна --- замінити іконками\
-   Адмінка --- остання по важливості\
-   Контент користувачів --- НЕ чіпати

------------------------------------------------------------------------
