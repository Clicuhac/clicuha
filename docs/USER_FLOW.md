# 🧭 USER FLOW --- Clicuha

Цей документ описує логіку руху користувача по сайту Clicuha: від
першого входу --- до створення клікухи, взаємодії з контентом та
можливих майбутніх сценаріїв.

------------------------------------------------------------------------

# 1️⃣ Вхід користувача на сайт

## ✔️ Крок 1: Користувач відкриває головну сторінку `/`

На головній він бачить: - коротке пояснення, що таке Clicuha\
- останні клікухи\
- кнопки: - "Створити клікуху" - "Увійти в адмінку" (для адмінів)

------------------------------------------------------------------------

# 2️⃣ Створення клікухи

## ✔️ Крок 2: Користувач натискає "Створити клікуху"

→ переходить на `/nicknames/create.php`

### Форма включає:

-   Title (назва)
-   Description (опис)
-   Checkbox "Анонімно"
-   Submit

## ✔️ Крок 3: Валідація

Система перевіряє: - чи не пустий заголовок - чи коректний опис - чи не
надто довгий текст

## ✔️ Крок 4: Збереження в БД

-   створюється запис у таблиці `nicknames`
-   генерується slug
-   зберігається автор (якщо є сесія)

------------------------------------------------------------------------

# 3️⃣ Перегляд клікухи

## ✔️ Крок 5: Редірект на створену клікуху

URL виду:

    /nickname.php?id=123

Користувач бачить: - назву - опис - статус анонімності - кнопки: -
"Редагувати" (якщо автор) - "Коментувати" (коли модуль готовий) - "Лайк"
(майбутнє)

------------------------------------------------------------------------

# 4️⃣ Редагування клікухи

## ✔️ Крок 6: Якщо користувач автор

→ може натиснути "Редагувати"

Переходить на:

    /nicknames/edit.php?id=123

Редагує: - заголовок - опис - checkbox анонімності

------------------------------------------------------------------------

# 5️⃣ Авторизація (для адмінів)

## ✔️ Крок 7: Натискання "Увійти"

→ `/login.php`

Після успішного входу: - сесія створюється - user.role = admin → доступ
до адмінки

------------------------------------------------------------------------

# 6️⃣ Адмін-панель

## ✔️ Крок 8: Адмін заходить на `/admin/`

Бачить: - список клікух - список користувачів - посилання на техсторінки
(health, логи, статус деплою)

## ✔️ Крок 9: Дії адміна

-   редагувати/видаляти клікухи
-   переглядати користувачів
-   бачити внутрішні статуси

------------------------------------------------------------------------

# 7️⃣ Коментарі (майбутній потік)

## Кроки:

1.  На сторінці клікухи → натиснути "Коментувати"
2.  Форма →
    -   текст
    -   submit
3.  Збереження в таблиці `comments`
4.  Відображення під клікухою

------------------------------------------------------------------------

# 8️⃣ Лайки (майбутній потік)

1.  Користувач натискає ❤️
2.  AJAX/API запит → `/api/like`
3.  Таблиця `likes` оновлюється
4.  Лічильник оновлюється на сторінці

------------------------------------------------------------------------

# 9️⃣ Feed (стрічка) --- майбутній потік

Користувач переходить на `/feed/`:

Бачить: - нові клікухи - нові коментарі - активність адмінів - лайки

------------------------------------------------------------------------
