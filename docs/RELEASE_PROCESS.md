# 🚀 RELEASE_PROCESS.md --- Clicuha

Документ описує офіційний процес створення релізів Clicuha: як
оновлювати сайт, як позначати версії, як оформлювати зміни та як уникати
помилок.

------------------------------------------------------------------------

# 1️⃣ Типи релізів

Умовно ділимо релізи на 3 рівні:

### **1) Patch (малий реліз)**

-   дрібні виправлення
-   стилі, тексти, невеликі правки
-   версія: `v1.0.1`

### **2) Minor (функціональний реліз)**

-   нові фічі (коментарі, лайки, feed)
-   помітні зміни в UI
-   версія: `v1.1.0`

### **3) Major (великий реліз)**

-   масштабні зміни архітектури
-   нові модулі (duels, AI assistants)
-   версія: `v2.0.0`

------------------------------------------------------------------------

# 2️⃣ Гілки для роботи

### 🔵 `dev`

-   тестова гілка
-   всі зміни спочатку йдуть сюди
-   автодеплой на `dev.clicuha.com`

### 🟢 `main`

-   бойова гілка
-   все, що тут → одразу на `clicuha.com`

------------------------------------------------------------------------

# 3️⃣ Підготовка до релізу

1.  Завершити роботу в `dev`

2.  Перевірити:

    -   не лишилося файлів з debug-кодом
    -   немає `var_dump()`, `print_r()`
    -   відсутні тимчасові файли

3.  Оновити документацію:

    -   `docs/`
    -   README

4.  Провести ручне тестування

5.  Створити фінальний commit:

        chore: prepare release v1.0.0

------------------------------------------------------------------------

# 4️⃣ Створення релізу

## ✔️ Крок 1. Злиття `dev` → `main`

    git checkout main
    git merge dev
    git push origin main

## ✔️ Крок 2. Створити git-тег

    git tag v1.0.0
    git push origin v1.0.0

## ✔️ Крок 3. GitHub Release (опціонально)

У репо → **Releases → Draft new release**

Вказати: - тег: `v1.0.0` - назва: `Release v1.0.0` - список змін

------------------------------------------------------------------------

------------------------------------------------------------------------

# 6️⃣ Деплой

Після push у `main` → автодеплой запускається автоматично.

Потрібно перевірити: - https://clicuha.com працює - немає помилок у
консолі - `health.php` → OK

------------------------------------------------------------------------

# 7️⃣ У разі проблем

Якщо реліз зламав сайт:

1.  Відкотити до попереднього тегу:

```{=html}
<!-- -->
```
    git checkout v1.0.0

2.  Запустити деплой:

```{=html}
<!-- -->
```
    bash deploy.sh

3.  Переробити реліз
