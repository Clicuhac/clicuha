# 🏛 Architecture Overview --- Clicuha

Цей документ дає загальне уявлення про структуру Clicuha: як
організований код, які модулі існують, як вони взаємодіють між собою.

------------------------------------------------------------------------

## 📁 1. Основна структура проєкту

    /clicuha
    ├── admin/              # Адмінка, керування користувачами та налаштуваннями
    ├── assets/             # CSS, JS, картинки, шрифти
    ├── nicknames/          # Модуль "Клікухи": створення, редагування, перегляд
    ├── functions.php       # Глобальні функції проєкту
    ├── config.php          # Підключення до БД та конфігурація
    ├── index.php           # Головна сторінка сайту
    └── docs/               # Документація

-   `/public_html` --- окрема копія, створена автодеплоєм (її вручну не
    чіпаємо).
-   `/clicuha` --- "євангеліє" сайту, єдиний правильний код.

------------------------------------------------------------------------

## 🗄 2. Структура бази даних (коротко)

### Таблиця `users`

-   id
-   email
-   password_hash
-   role
-   created_at

### Таблиця `nicknames`

-   id
-   title
-   slug
-   description
-   anonymous
-   created_by
-   created_at

### Таблиця `comments` (планується)

-   id
-   nickname_id
-   user_id
-   text
-   created_at

------------------------------------------------------------------------

## 🔌 3. Основні модулі

### **1) Nicknames**

-   створення нової клікухи
-   slug-генерація
-   анонімність (checkbox)
-   перегляд сторінки клікухи

### **2) Admin**

-   список користувачів
-   список клікух
-   можливість редагувати/видаляти

### **3) Core (ядро)**

-   `config.php` --- підключення до MySQL
-   `functions.php` --- утиліти (транслит, безпека, валідатори)
-   роутінг через `index.php` (простий, без фреймворку)

------------------------------------------------------------------------

## 🔄 4. Як працює запит

1.  Користувач заходить на адресу\
    `https://clicuha.com/nickname.php?id=123`
2.  PHP читає параметр `id`
3.  Виконує SQL → отримує клікуху з БД
4.  Збирає HTML через відповідний шаблон
5.  Виводить сторінку

------------------------------------------------------------------------

## 🚀 5. Деплой та середовища

-   **main** → продакшн (clicuha.com)
-   **dev** → тест (dev.clicuha.com)
-   Автодеплой через webhook + `deploy.sh`

------------------------------------------------------------------------

## 🧱 6. Плани розширення архітектури

-   `/api/` --- окремий REST API
-   `/duel/` --- модуль поєдинків між юзерами
-   `/ai/` --- модуль "Асистенти"
-   `/feed/` --- стрічка подій
-   `/market/` --- маркетплейс клікух
