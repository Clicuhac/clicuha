# 🗄 Database Schema --- Clicuha

Цей документ описує структуру бази даних Clicuha: таблиці, поля, зв'язки
між ними та логіку використання.

------------------------------------------------------------------------

## 📌 1. Таблиця `users`

Зберігає інформацію про користувачів.

  Поле            Тип                Опис
  --------------- ------------------ --------------------------
  id              INT PK AI          Унікальний ідентифікатор
  email           VARCHAR(255)       Логін користувача
  password_hash   VARCHAR(255)       Хеш паролю
  role            ENUM(admin,user)   Роль у системі
  created_at      DATETIME           Дата створення

------------------------------------------------------------------------

## 📌 2. Таблиця `nicknames`

Головна таблиця проєкту --- зберігає всі "клікухи".

  ---------------------------------------------------------------------------
  Поле                        Тип                             Опис
  --------------------------- ------------------------------- ---------------
  id                          INT PK AI                       Унікальний ID

  title                       VARCHAR(255)                    Назва клікухи

  slug                        VARCHAR(255)                    Унікальний
                                                              URL-friendly
                                                              ідентифікатор

  description                 TEXT                            Опис

  anonymous                   TINYINT(1)                      1 = анонімна, 0
                                                              = відкрита

  created_by                  INT FK                          Автор
                                                              (users.id)

  created_at                  DATETIME                        Дата створення
  ---------------------------------------------------------------------------

🔗 **FK:** `created_by → users.id`

------------------------------------------------------------------------

## 📌 3. Таблиця `comments` (планується)

Система коментарів до клікух.

  Поле          Тип         Опис
  ------------- ----------- -----------------
  id            INT PK AI   Унікальний ID
  nickname_id   INT FK      До якої клікухи
  user_id       INT FK      Хто написав
  text          TEXT        Текст коментаря
  created_at    DATETIME    Дата

🔗 **FK:** - `nickname_id → nicknames.id` - `user_id → users.id`

------------------------------------------------------------------------

## 📌 4. Таблиця `likes` (можлива майбутня)

Оцінки клікух або коментарів.

  Поле          Тип                          Опис
  ------------- ---------------------------- ------------------------
  id            INT AI                       Унікальний ID
  user_id       INT FK                       Хто лайкнув
  target_id     INT                          ID клікухи або комента
  target_type   ENUM('nickname','comment')   Тип об'єкта
  created_at    DATETIME                     Дата

------------------------------------------------------------------------

## 📌 5. Зв'язки між таблицями

    users (1) ──────── (∞) nicknames
                  ↳ created_by

    users (1) ──────── (∞) comments
                  ↳ user_id

    nicknames (1) ──── (∞) comments
                  ↳ nickname_id

------------------------------------------------------------------------

## 📌 6. Загальні вимоги до БД

-   Використовувати `utf8mb4_unicode_ci`
-   Первинні ключі: INT AUTO_INCREMENT
-   Дати зберігати у `DATETIME`, не TIMESTAMP
-   Суворо уникати NULL там, де це можливо
-   Усі FK повинні бути з обмеженням `ON DELETE CASCADE`

------------------------------------------------------------------------

## ✔️ 7. Висновок

Це офіційна схема бази даних Clicuha, яку можна розширювати в міру
додавання нових модулів.
