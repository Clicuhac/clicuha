# 📦 Modules Development Plan --- Clicuha

Цей документ описує поетапний розвиток модулів Clicuha --- що вже є, що
в роботі, що планується, і які пріоритети.

------------------------------------------------------------------------

## ✅ 1. Наявні модулі (готові / працюють)

### **1) Nicknames**

-   створення клікухи
-   редагування
-   анонімність
-   slug-генерація
-   перегляд сторінки

### **2) Admin**

-   перегляд списку клікух
-   перегляд списку користувачів

### **3) Core**

-   `config.php`
-   `functions.php`
-   базові утиліти
-   підключення до БД

------------------------------------------------------------------------

## 🔧 2. Модулі в процесі (робимо зараз або найближчим часом)

### **1) Documentation system (docs/)**

-   DevOps план --- ✔️
-   Архітектура --- ✔️
-   БД --- ✔️
-   Routing Map --- ✔️
-   Інші документи --- в роботі

### **2) UI/UX покращення**

-   структура меню
-   видимість кнопок
-   адаптивність
-   кольорова схема

### **3) Авторизація (оновлення системи логіну)**

-   переписати login/logout
-   захист адмінки
-   уніфіковані сесії

------------------------------------------------------------------------

## 🚀 3. Модулі, які заплановані найближчими (високий пріоритет)

### **1) Коментарі**

-   таблиця `comments`
-   форма коментаря на сторінці клікухи
-   модерація
-   пагінація

### **2) Лайки**

-   таблиця `likes`
-   лайки клікух і коментарів
-   захист від накрутки

### **3) Feed (стрічка)**

Показ: - нових клікух - нових коментарів - активності користувачів

------------------------------------------------------------------------

## 🧠 4. Модулі середнього пріоритету

### **1) Duel**

-   система викликів
-   арбітраж
-   AI-асистенти як учасники
-   рейтинг

### **2) AI Assistants**

-   персональні "клікухи-боти"
-   окремі чати
-   сценарії
-   лог персонажів

### **3) Notifications**

-   email-повідомлення
-   внутрішні сповіщення
-   підписки на клікухи

------------------------------------------------------------------------

## 🏛 5. Модулі майбутнього (але дуже бажані)

### **1) Marketplace**

-   продаж клікух
-   обмін
-   ліцензії на персонажів
-   токенізація (опційно)

### **2) API (REST)**

-   загальний публічний API
-   документація OpenAPI
-   інтеграції з мобільним застосунком

### **3) Multilanguage 2.0**

-   повне винесення текстів у словники
-   підтримка 10+ мов
-   автообрання мови
