# 🧭 Routing Map --- Clicuha

Цей документ описує основні маршрути (URL → PHP-скрипти) та їхню роль у
роботі сайту Clicuha.

------------------------------------------------------------------------

## 🌐 1. Публічні сторінки

### `/` → `index.php`

-   Головна сторінка сайту.
-   Може містити:
    -   список останніх клікух;
    -   загальний опис проєкту;
    -   навігацію по розділах.

------------------------------------------------------------------------

### `/nickname.php?id={id}` → `nickname.php` / `nicknames/view.php`

-   Відображення окремої клікухи.
-   Параметри:
    -   `id` --- ID клікухи в таблиці `nicknames`.
-   Логіка:
    -   зчитати `id`;
    -   знайти запис у БД;
    -   показати заголовок, опис, статус анонімності.

------------------------------------------------------------------------

### `/nicknames` → `nicknames/index.php` (планується)

-   Список усіх (або останніх) клікух.
-   Пагінація, фільтри, пошук.

------------------------------------------------------------------------

## 🧑‍💻 2. Сторінки створення/редагування

### `/nicknames/create.php`

-   Форма створення нової клікухи.
-   Поля:
    -   title
    -   description
    -   anonymous (checkbox)
-   Дії:
    -   валідація;
    -   запис у `nicknames`;
    -   генерація `slug`.

------------------------------------------------------------------------

### `/nicknames/edit.php?id={id}`

-   Редагування існуючої клікухи.
-   Параметри:
    -   `id` --- ID клікухи.
-   Дії:
    -   завантажити поточні дані;
    -   показати форму;
    -   оновити БД.

------------------------------------------------------------------------

## 🔐 3. Авторизація / акаунти (якщо використовується)

### `/login.php`

-   Сторінка входу.
-   Перевірка:
    -   email
    -   password
-   Успіх → створення сесії, редірект у адмінку.

------------------------------------------------------------------------

### `/logout.php`

-   Вихід із системи.
-   Очищення сесії/куків.
-   Редірект на головну.

------------------------------------------------------------------------

## 🛠 4. Адмінка

### `/admin/index.php`

-   Головна сторінка адмін-панелі.
-   Може містити:
    -   лінки на списки користувачів, клікух;
    -   базову статистику.

------------------------------------------------------------------------

### `/admin/users.php`

-   Список користувачів.
-   Функції:
    -   перегляд;
    -   можливо --- блокування/видалення.

------------------------------------------------------------------------

### `/admin/nicknames.php`

-   Список усіх клікух.
-   Функції:
    -   перегляд;
    -   редагування;
    -   видалення.

------------------------------------------------------------------------

## ❤️ 5. Службові / технічні маршрути

### `/health.php`

-   Простий "healthcheck" сайту.
-   Відповідає "OK" або віддає базову діагностику.

------------------------------------------------------------------------

### `/test_ssh.txt`, `_host_ok.txt`

-   Тестові файли для перевірки:
    -   доступу до сервера;
    -   работи SSH/деплою.

------------------------------------------------------------------------

## 🚀 6. Майбутні маршрути

Планується реалізувати:

### `/duel/`

-   Розділ дуелей між користувачами/асистентами.

### `/ai/`

-   Панель взаємодії з AI-асистентами.

### `/feed/`

-   Стрічка активності (нові клікухи, коментарі).

### `/market/`

-   Маркетплейс клікух, мемів, контенту.

------------------------------------------------------------------------

## ✔️ 7. Висновок

Ця карта маршрутів дає загальне уявлення, як URL співвідносяться з
PHP-файлами та логікою.\
Документ можна доповнювати в міру появи нових сторінок і модулів.
